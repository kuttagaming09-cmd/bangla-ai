# Bangla AI — সহজ বাংলা সহকারী

একটি ছোট, দ্রুত এবং ইনস্টলেশনবিহীন বাংলা সহকারী। এটি পুরোপুরি ব্রাউজারে চলে—কোনো API key, আলাদা সার্ভার, মডেল ডাউনলোড বা সফটওয়্যার ইনস্টল লাগে না।

## কী পারে

- বাংলা শুভেচ্ছা, নাম মনে রাখা, তারিখ ও সময় বলা
- ছোট যোগ-বিয়োগ, গুণ-ভাগ ও শতাংশের হিসাব
- সাধারণ প্রশ্নে সংক্ষিপ্ত উত্তর
- সর্বশেষ ১২টি বার্তা এই ডিভাইসের ব্রাউজারে রাখা
- মোবাইল ও ডেস্কটপে ব্যবহারযোগ্য responsive UI

## কী পারে না

এটি একটি হালকা rule-based assistant, বড় ভাষা মডেল নয়। লাইভ খবর/আবহাওয়া, গভীর গবেষণা, বড় কোড লেখা, পেশাদার সিদ্ধান্ত বা উচ্চ-স্তরের reasoning-এর জন্য এটি তৈরি নয়।

## লোকালি চালানো

কোনো build step নেই। যেকোনো static server চালান:

```bash
python3 -m http.server 3000
```

তারপর `http://localhost:3000` খুলুন।

## GitHub Pages

1. এই repository-র **Settings → Pages** খুলুন।
2. **Deploy from a branch** বেছে নিন।
3. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করুন।
4. Save করার পর GitHub যে Pages URL দেবে সেটি খুলুন।

## গোপনীয়তা

বার্তা কোনো সার্ভারে পাঠানো হয় না। কথোপকথন কেবল এই ব্রাউজারের `localStorage`-এ থাকে। ব্রাউজারের site data মুছলে স্মৃতিও মুছে যাবে।
